# Evaluation Datasets

This directory will contain curated test datasets for evaluating
AI capability quality.

## Future contents

- Sample CVs (anonymised) for CV Analyzer evaluation
- Sample job descriptions for Job Matching evaluation
- Expected outputs for regression testing
- Edge cases and adversarial inputs

## Rules

- **Do NOT commit real personal data** — use anonymised or synthetic data only.
- Each dataset should include both input and expected output.
- Datasets should cover common cases, edge cases, and failure modes.

## Status

**Not yet created.** Datasets will be prepared during implementation phase.
